# 🧬 Inheritance in Python

## 📖 Introduction

**Inheritance** is one of the most important concepts of **Object-Oriented Programming (OOP)** in Python. It allows one class to acquire the properties and behaviors of another class.

Inheritance helps developers write **cleaner, reusable, and well-organized code**.

---

## 🔍 What is Inheritance?

Inheritance is a mechanism in which a **child class** inherits the attributes and methods of a **parent class**.

### Important Terms

* **Parent Class / Base Class / Superclass:** The class whose properties are inherited.
* **Child Class / Derived Class / Subclass:** The class that inherits properties from another class.

A child class can use the existing functionality of its parent class and can also add new features of its own.

---

## 📝 Basic Syntax

The basic syntax of inheritance involves:

1. Creating a **parent class**.
2. Creating a **child class**.
3. Mentioning the parent class while defining the child class.

The child class can access the methods and attributes of the parent class and can also modify or extend its functionality.

---

# 🧩 Types of Inheritance

Python supports several types of inheritance.

## 1️⃣ Single Inheritance

In **Single Inheritance**, one child class inherits from one parent class.

It is the simplest and most commonly used type of inheritance.

---

## 2️⃣ Multiple Inheritance

In **Multiple Inheritance**, one child class inherits properties and methods from more than one parent class.

This allows a class to combine functionality from multiple sources.

---

## 3️⃣ Multilevel Inheritance

In **Multilevel Inheritance**, inheritance occurs in multiple levels.

A child class can become a parent class for another class, creating a chain of inheritance.

---

## 4️⃣ Hierarchical Inheritance

In **Hierarchical Inheritance**, multiple child classes inherit from a single parent class.

Each child class can use common features from the parent class while having its own unique functionality.

---

## 5️⃣ Hybrid Inheritance

**Hybrid Inheritance** is a combination of two or more types of inheritance.

It provides flexibility when designing complex class relationships.

---

# ✨ Features of Inheritance

Inheritance provides several useful features:

### ♻️ Code Reusability

Existing functionality can be reused without writing the same code again.

### 🚀 Extensibility

New features can be added to child classes without changing the parent class.

### 🔄 Method Overriding

A child class can provide its own implementation of a method inherited from the parent class.

### 🛠️ Easy Maintenance

Common functionality can be placed in one parent class, making the program easier to maintain.

### 🏗️ Better Code Organization

Inheritance helps organize classes according to their relationships and responsibilities.

---

# 💡 Conceptual Example

Imagine a general class called **Vehicle**.

The Vehicle class contains common characteristics that can be shared by different types of vehicles.

Classes such as **Car**, **Bike**, and **Truck** can inherit these common characteristics while also having their own unique features.

This reduces code duplication and makes the program easier to expand.
